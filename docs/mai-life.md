# 和麦生活联动

[← 返回 README](../README.md)

[麦生活（Mai_life）](https://github.com/octmicy/Mai_life) 给 Bot 排每天的日程（睡觉、上班、吃饭、通勤、休闲……），还会找机会主动私聊分享她的生活。两个插件都装上时：

- **自动玩按日程来**：休闲时玩、睡觉时不玩，一次最多玩到这段日程结束。
- **上班偶尔摸鱼**：上班、上课时按小概率偷偷玩几分钟。
- **玩完交给麦生活分享**：刷到的东西由麦生活找机会在私聊里提起。

只影响自动玩。聊天里叫她玩、`/手机 开始`、WebUI 的「开始玩」都不看日程。麦生活那边不用设置，需要 1.23.5 及以上（这里按 1.26.0 实测）。

## 按日程自动玩

自动玩每次考虑要不要玩之前，先问麦生活她现在在做什么：

| 日程 | 自动玩 | 配置 |
|---|---|---|
| 休闲、休息、吃饭、在路上 | 照常按 `auto_play.play_probability` 的概率玩 | `life_link.play_kinds` |
| 上班、上课 | 偶尔摸鱼，见下一节 | `life_link.slack_kinds` |
| 睡觉、午睡 | 不玩 | 两边都没写的就不玩 |

- **玩多久**：不超过这段日程剩下的时间（也不超过 `play.max_session_minutes`）。剩下不到 `life_link.min_minutes`（默认 5 分钟）就这次先不玩。
- **玩什么**：开始时告诉她这段日程在做什么、在哪、此刻的情形（比如「坐地铁回家，站在车门边」），她挑内容时会参考。
- **查不到日程时照旧**：没装麦生活、它刚启动还没就绪、当天日程还没生成、正好是两段之间的空档，都按 `auto_play.active_hours`，原因写在状态里。
- 剩下多少时间用麦生活给的两个时刻相减，两边时区设置不一样也不影响；日程本身按麦生活配置的时区排，建议和 Bot 所在地一致。

## 上班摸鱼

日程是 `life_link.slack_kinds` 里的那几类（默认上班、上课）时，每次只按 `slack_probability`（默认 10%）的概率偷偷玩一会儿，最多 `slack_minutes`（默认 5）分钟：

- 开始时告诉她这是上班中途摸鱼，挑能随时放下的内容（刷几条短视频、看几条笔记），别一头扎进长视频和游戏，玩完接着干活。
- 操作记录和「最近玩过」里写「摸鱼」。
- 按默认每 30 分钟考虑一次，一个 8 小时的工作日平均摸一两次。
- 不想让她摸鱼就把 `slack_probability` 设成 0。

## 玩完交给麦生活分享

`life_link.share_after_play`，默认开。按日程自动玩、自然结束（她自己玩够了、到了时长或步数）的那一局，玩完把「刚才自己刷抖音看到的：……」（摸鱼的局是「刚才摸鱼偷偷刷抖音看到的：……」，后面是她自己的总结）交给麦生活的主动分享。之后由麦生活决定提不提、什么时候、跟谁提：

- 它只在自己配置的私聊用户里挑，照它的每日额度、免打扰、两次主动的间隔和「刚聊过不打扰」来；精力太低、睡着时不提。
- 它打分时从 `life_link.share_weight`（默认 0.4）起步，加上精力、心情、关系温度，过了它的阈值（默认 0.45）才交给 Planner，Planner 也可以选择不说。和她自己的生活事件一起排，不会每次玩完都说。
- 交过去的内容麦生活会当成外部资料，只判断值不值得当见闻分享，不会照着里面的话去做。两个小时内没提就作废。

不交给麦生活的局：

- 聊天里叫她玩的：已经会在那个聊天里提一句。
- 命令和 WebUI 开的：有人看着。
- 出错、卡住、被叫停的：没什么可分享。
- 没装麦生活、退回 `active_hours` 时开的。

## 在哪看

- **WebUI「今天」**：下面有一行「生活联动（13:47 查看）：按麦生活的日程，现在是「补齐项目表格」（工作 · 公司工位），偶尔摸鱼玩一会儿（每次考虑时 10% 的概率，最多 5 分钟）」。`/手机` 状态里也有。
- **操作记录**：自动玩开始时，第一行写着当时的日程；交没交给麦生活（「交给麦生活分享」或「没交给麦生活分享」加原因）写在最后，日志里也有。
- 看状态时一分钟最多问一次麦生活，自动玩每次都重新问。

## 配置

都在插件配置的「生活联动」（`life_link`）里，下表省略了前缀，比如总开关是 `life_link.enabled`：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `enabled` | 开 | 不想联动就关掉，自动玩回到只看 `active_hours` |
| `play_kinds` | `leisure`、`rest`、`meal`、`travel` | 日程是这几类时照常玩 |
| `slack_kinds` | `work`、`study` | 日程是这几类时偶尔摸鱼；也写在 `play_kinds` 里的按 `play_kinds` |
| `slack_probability` | 0.1 | 每次考虑摸鱼的概率，0 表示上班上课时不玩 |
| `slack_minutes` | 5 | 摸鱼一次最多玩几分钟 |
| `min_minutes` | 5 | 这段日程剩下不到这么多分钟就先不玩 |
| `share_after_play` | 开 | 玩完把看到的交给麦生活分享；只是不想让她提起就关掉这个 |
| `share_weight` | 0.4 | 交给麦生活时的分享权重，越高越容易被挑中 |

日程类别：`leisure` 休闲、`rest` 休息、`meal` 吃饭、`travel` 在路上、`study` 学习、`work` 工作、`nap` 午睡、`sleep` 睡觉，写中文也行。

```toml
[life_link]
enabled = true
play_kinds = ["leisure", "rest", "travel"]   # 也可以写中文：["休闲", "休息", "在路上"]
slack_kinds = ["work", "study"]
slack_probability = 0.1
slack_minutes = 5
min_minutes = 5
share_after_play = true
share_weight = 0.4
```
