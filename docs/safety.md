# 安全边界

[← 返回 README](../README.md)

> [!WARNING]
> 请用**闲置手机**和**专门注册的账号**。她能操作这台手机上登录的账号能做的事；可选的[互动](usage.md#互动)打开后，她会用这个账号**公开**点赞、评论、关注，平台可能把这类自动化操作判定为异常而限流甚至封号。

## 代码强制执行

不依赖模型听话：

| 限制 | 怎么做 |
|---|---|
| 白名单 | 只能打开 `safety.allowed_apps` 里、且手机上已安装的应用；每一步都会检查前台应用，停在白名单以外（桌面和 `extra_allowed_packages` 除外）就直接回桌面 |
| 输入文字 | 可整体关闭，并限制单次长度 |
| 次数和时长 | 单次最多步数 / 分钟数、每天最多次数 / 步数、连续出错自动结束 |
| 模型调用预算 | 一次最多 `play.max_model_calls_per_session` 次、每天最多 `play.daily_model_call_limit` 次，决定玩什么和每步看屏幕都算，调用失败、格式不对重来的也算；用完就正常收尾（记录这次玩了什么、按设置回桌面），不会半路丢下 |
| 卡住检测 | 同一个地方连点 5 次画面都没变、最近 6 步一直在两个画面之间来回切、同样的失败出现 4 次，就结束这次。看小说翻页、看视频等待、等对方出牌这类画面不变或重复是正常的，不算卡住 |
| 应用单独设置 | 绕不过全局上限：应用的 `max_minutes` 只能比全局 `play.max_session_minutes`（一起玩时是 `together_minutes`）更短；步间隔最少 0.5 秒；步数、每日额度、模型调用预算、白名单检查都不受应用设置影响 |
| 互动 | 开启后：点赞、评论、关注每天的次数上限，评论的长度上限，评论里不能有链接、@ 和联系方式；没开启时 `like`、`comment`、`follow` 一律拒绝 |
| 点之前核对 | 从截图到点下去隔着一次模型调用（几秒到十几秒），弹窗可能已经自己收起、列表可能动了。所以点击、长按、点赞、关注、点评论框之前先截一张新图比对要点的地方；变了就重新读界面，要点的东西不在原处就这一步不点，让她看了新画面再决定。读不到界面元素的画面（游戏、部分视频页）没法核对，照原样点 |
| 权限 | 控制命令、截图命令、切换设备只有管理员能用 |

## 只在提示词里要求

模型可能违反：

- 不发弹幕、私信，不付款、不登录。
- 没开启互动时也不发评论、不关注（她用普通的点击、输入也能做到，代码拦不住）。

所以请务必使用独立设备和不重要的账号。

## 其他要注意的

- **WDA 没有密码**：iPhone 上的 WebDriverAgent 在手机的 Wi-Fi 上也开着端口，同一个局域网里的人都能控制这台手机。只在信任的网络里用，不玩的时候关掉，见[准备 iPhone](iphone.md#6-启动-wda)。
- **截图会发给模型**：手机上的通知、聊天弹窗会被截进去。iPhone 建议打开勿扰或专注模式；聊天里的截图默认只有管理员能看（`plugin.screenshot_for_everyone`）。
- **WebUI 不受管理员限制**：能登录 WebUI 就能开始、停止、接管、切换设备，请只给信任的人 WebUI 访问权限。
