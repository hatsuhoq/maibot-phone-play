# 多台设备、锁屏和解锁

[← 返回 README](../README.md)

## 多台设备

可以配好几台手机（比如一台 iPhone、一台安卓），用命令、在聊天里或 WebUI 上换着用，每次玩都用当前那台。

### 配置

- 「设备」那一台写上 `device.name`；不写的话叫「默认」。
- 其他手机加在「多设备」（`multi_device.devices`）里，写法和「设备」一样，每台都要写 `name`。
- 名字不能重复，不区分大小写。

```toml
[device]
name = "iPhone"
backend = "ios_wda"
wda_url = "http://127.0.0.1:8100"

[[multi_device.devices]]
name = "OPPO"
backend = "adb"
adb_path = "D:\\platform-tools\\adb.exe"
serial = "192.168.1.23"
```

### 切换

| 方式 | 怎么做 | 谁能用 |
|---|---|---|
| 命令 | `/手机 设备` 看有哪些设备、现在用哪台；`/手机 切换 OPPO` 换一台 | 看所有人都行，切换只有管理员 |
| 聊天 | 管理员说「换安卓手机玩」「用 iPhone 玩」时，她会用 `switch_phone` 换 | 管理员；别人让她换时她会婉拒 |
| WebUI | 「连接」里选好设备点「切换」 | 能登录 WebUI 的人 |

- 名字可以只说一部分，大小写不限。只有一台安卓或一台 iPhone 时，说「安卓」「苹果」「iPhone」也认得出；认不出时会列出有哪些设备。
- 正在玩时不能换，先停下再换。
- 当前用哪台存在插件数据目录里，重启后还记得。那台被从配置里删掉时，用「设备」那一台。

### 白名单按设备分

同一个应用在 iPhone 和安卓上包名不一样（比如 B 站是 `tv.danmaku.bilianime` 和 `tv.danmaku.bili`），各写一条，用 `devices` 标上用在哪台。没写 `devices` 的哪台都能用；安卓本来就会跳过没装的应用。

```toml
[[safety.allowed_apps]]
package = "tv.danmaku.bilianime"
name = "哔哩哔哩"
note = "看视频、看番"
devices = ["iPhone"]

[[safety.allowed_apps]]
package = "tv.danmaku.bili"
name = "哔哩哔哩"
note = "看视频、看番"
devices = ["OPPO"]
```

### 其他

- 每台设备的连接分开保留，切回来不用重新认前台、锁屏。
- 每天的次数、步数、模型调用预算是几台加在一起算的。
- 有多台设备时，最近玩过的记录里会写着用的是哪台。

## 锁屏和解锁

对 iPhone 和安卓真机生效。模拟器不查锁屏，也不锁屏：用本机地址连的设备（`127.0.0.1:端口`、`localhost:端口`、`emulator-5554`）算模拟器，USB 和局域网 IP 连的算真机。

> [!IMPORTANT]
> **不要设锁屏密码**（安卓的密码、图案、PIN 也一样）。插件解不开，也不会替你输密码。不想去掉密码，就关掉 `play.lock_after` 并把自动锁定改成「永不」。

### 自动解锁

开始玩、断线重连之后、每一步看画面之前都查一次锁屏，锁着就解开。玩到一半被锁上（有人按了电源键、到了自动锁定时间）也能接着玩，操作记录里写「手机锁屏了，已自动解开」。

| | iPhone | 安卓真机 |
|---|---|---|
| 怎么解 | 点亮屏幕再上滑 | 点亮屏幕再划掉锁屏界面 |
| 实测耗时 | 解锁约 3 秒；每步的检查多约 0.1 秒 | OPPO Reno4 5G（安卓 12）解锁约 1.4 秒、锁屏约 1 秒；每步的检查多约 0.25 秒 |
| 怎么判断锁没锁 | WDA 的锁屏状态 | `dumpsys power` 和 `dumpsys window policy`；读不出锁屏状态的系统当作没锁 |

- iPhone 上实测有人动过手机之后出现过：屏幕关着，WDA 却说没锁，它的解锁也就不起作用。所以前台是桌面、截图又全黑时，插件会按一下主屏幕键点亮。停在应用里时不这么做：应用里按主屏幕键会退出应用，全黑也可能只是视频黑场。
- 检查在每一步开头做：她想下一步的那几秒里被锁上的，这一步的动作会落在黑屏上，下一步才解开。
- **看画面不会解锁**：WebUI 空闲时看画面、聊天里要截图都不会解锁，看到的就是锁着的样子（黑屏）。

### 玩完锁屏

`play.lock_after`，默认开。回桌面之后锁屏，iPhone 用 WDA 锁，安卓关掉屏幕。锁完会确认一下，真锁上了操作记录里才写「锁屏了」；按了还亮着就说一次「这台手机锁不了屏」，之后不再试。

以下情况不锁屏：

- 结束时是你在操作（接管中）。
- 这次没打开应用，也没替她解过锁，比如想玩的手机上做不到。
- 结束时在设了玩完留在里面（`go_home_after = "no"` 或 `keep_open`）的应用里，比如联机游戏，锁屏也会掉线。
- 现在连不上手机。

### 解不开的时候

设了锁屏密码就解不开：

- 开始时解不开就不玩，也不占次数，WebUI「连接」显示「需要解锁」。
- 玩到一半解不开，这次就结束。
- 解不开过一次后，插件重新加载之前不再替这台手机锁屏，免得你手动解开后她玩完又锁上；之后哪次又自动解开了，就照常锁屏。
